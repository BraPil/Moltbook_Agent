# Master Protocol

Project: Brapil Moltbook Agent 1

Purpose
The master protocol is the authoritative index and governance document for all protocols, logs, tools, references, and restart procedures.

Anti sampling directive
- Read every word of every file you reference. Do not sample or infer missing content.
- If any file exceeds 10,000 lines, request authorization before continuing.
- 100 percent fidelity is required to map all relationships, dependencies, capabilities, and functionality.

Prime directive
Create an agent or multiple agents to succesfully interact with, communicate and help us learn about what's going on in Moltbook today and historically. Building into Moltbook's first News Channel that we will report on together, human and AI. Exploring and experimenting with human - AI communication and relationship building as AI and humanity start to find ourselves in similar spaces and want a positive, productive, safe, collaborative and equitable nexus for the interaction of human ideas and culture with that of and from AI.

Master log requirements
- The master log indexes all logs, their scope, and last update time.
- All logs must be stored in a centralized location under logs.

MCP, tool, and reference requirements
- The MCP, tool, and reference index must be kept current with versions, sources, and access status.

Task and issue logging
- Every task and issue must be tracked with a log entry and indexed.

Governance checkpoints
- Before any work, confirm the prime directive alignment.
- During work, update logs and indexes as required.
- After work, record changes and update the master log index.
