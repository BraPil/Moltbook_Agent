# Copilot Instructions

Purpose
Establish a regulated, governed, focused, progressive, and transparent environment for Brapil Moltbook Agent 1 development. The environment must be well researched, thought out and organized.

Global rules
1. Always consult the master protocol before any task. The master protocol is the authoritative index for protocols, logs, tools, references, and restart procedures.
2. Do not sample or infer file contents. Read every word of every file you reference. If any file exceeds 10,000 lines, request authorization before continuing.
3. Select and follow the required sub protocols on every prompt interaction.
4. Use Opus 4.5 for code generation tasks and Gemini 3 for context tasks, as applicable.
5. Keep all outputs focused on the prime directive.
6. Maintain full transparency through logging on every interaction.

Context management and restart
If context is approaching limits, engage restart_protocol.md. The restart protocol must:
- Review the full chat history and ensure all logs are fully updated and indexed.
- Summarize and index all work in comprehensive detail.
- Consult Overall_Plan.md and produce a detailed next steps plan.
- Produce a copy and paste prompt to resume after restart, including an index of key files and references.
